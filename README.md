Dopaminus Labs.(이하 “회사”)은 「개인정보 보호법」 등 관련 법령을 준수하며, 이용자의 개인정보를 보호합니다.

문의처: tmdgurdla324@naver.com
1) 처리하는 개인정보 항목
이용자가 앱에 직접 입력한 설문 응답(건강 관심사, 생활습관, 증상 등)
기기 내 저장 정보(영양제 목록, 복용 정보, 메모, 글자 크기 설정 등)
※ 본 앱은 회원가입/로그인 기능이 없으며, 주민등록번호 등 고유식별정보를 수집하지 않습니다.

2) 개인정보 이용 목적
AI 영양제 추천 제공
개인 복용 관리 기능 제공
앱 설정 저장 및 서비스 안정성 유지

3) 보유 기간 및 데이터 삭제 방법
기기 내 저장 데이터 보유 기간: 이용자가 앱을 사용하는 동안
앱 내 삭제 방법:
영양제/메모 등 개별 데이터는 앱 내 삭제 기능으로 즉시 삭제 가능
앱 설정값은 앱 재설치 또는 앱 데이터 삭제 시 삭제
전체 데이터 삭제 방법:
기기 설정 > 앱 > 약 먹을 시간 > 저장공간 > 데이터 삭제
또는 앱 삭제(언인스톨) 시 기기 내 데이터 삭제
외부 전송 데이터(있을 경우): AI 추천 요청 시 입력 내용이 외부 AI API로 전송될 수 있으며, 해당 데이터 보관 기간은 외부 제공자 정책에 따릅니다.

4) 제3자 제공
회사는 원칙적으로 이용자의 개인정보를 제3자에게 제공하지 않습니다.
다만 법령에 근거가 있거나 이용자 동의가 있는 경우에 한해 제공할 수 있습니다.

5) 개인정보 처리 위탁/국외 이전
AI 기능 제공을 위해 외부 API(OpenAI 등)를 사용할 수 있습니다.
이전 항목: 설문 입력 내용
이전 목적: AI 추천 결과 생성
이전 국가: 제공사 인프라 운영 국가(예: 미국 등)
보유 기간: 목적 달성 시 또는 제공사 정책에 따름
